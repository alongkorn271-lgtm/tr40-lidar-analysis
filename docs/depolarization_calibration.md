# Depolarization calibration ของ TR40 prototype

**สถานะ:** calibration แบบที่โปรแกรมใช้อยู่ให้ δ ต่ำเกินจริงประมาณ 2–2.5 เท่า · **ข้อมูลที่ใช้วิเคราะห์:** 2026-09-08 (C01, 3.75 m) และ 2026-09-09 (C02, 30 m) ช่วงกลางคืน · **สิ่งที่ต้องทำ:** ทดลอง calibration แบบ ±45° กับเครื่องจริง

---

## 1. สรุปสั้น

- **δ ที่โปรแกรมรายงานต่ำกว่า Mini-MPL ประมาณ 2–2.5 เท่า** และสาเหตุหลักคือค่า calibration ไม่ใช่การประมวลผลสัญญาณ
- โปรแกรมหาค่า calibration ด้วย**วิธี molecular** (สมมติว่าอากาศที่ 4.5–5.5 km บริสุทธิ์) ได้ค่า **C ≈ 2.4–2.8** ส่วนข้อมูลบอกว่า**ค่าที่ควรเป็นคือ C ≈ 1.0**
- วิธี molecular กับเครื่องนี้**เชื่อถือไม่ได้** จากสาเหตุ 3 ข้อ (ข้อ 4)
- วิธีที่ถูกต้องตามมาตรฐาน EARLINET คือ **±45° calibration** ต้องทดลองกับเครื่องจริง (ข้อ 6)
- ⚠️ การใช้ MPL หาค่า C **ใช้เป็นข้อมูลอ้างอิงได้ แต่ใช้แทน calibration ไม่ได้** เพราะเรารู้ calibration ของ MPL ไม่ได้ และจะเลิกใช้ MPL ในอนาคต

---

## 2. Calibration คืออะไร

เครื่องแยกแสงที่กลับมาเป็นสองช่องด้วย polarizing beam splitter (PBS):

- **ช่อง ∥ (co / parallel):** แสงที่ขนานกับโพลาไรเซชันของเลเซอร์
- **ช่อง ⊥ (cross / perpendicular):** แสงที่ตั้งฉาก

สิ่งที่ต้องการคือ **volume depolarization ratio** ของบรรยากาศ

```
δ_v(z) = β⊥(z) / β∥(z)
```

แต่สิ่งที่เครื่องวัดได้คืออัตราส่วนของสัญญาณ ซึ่งมีความไวของแต่ละช่องปนอยู่

```
δ*(z) = P⊥(z) / P∥(z) = η* · δ_v(z)        η* = η⊥ / η∥
```

**η\*** (ในโปรแกรมเรียก **C**) คืออัตราส่วน "ความไว" ของสองช่อง รวมผลของ:
- gain ของ PMT แต่ละตัว (เปลี่ยนตาม HV)
- การส่งผ่าน/สะท้อนของ PBS ที่ไม่เท่ากันในสองทาง
- filter, เลนส์, ตัวต่อ และ electronics ของแต่ละช่อง (TR0 กับ TR1)

**calibration คือการหาค่า η\*** แล้วคำนวณ

```
δ_v(z) = δ*(z) / η*
```

ถ้า η\* ผิดไป k เท่า δ ทุกระยะจะผิดไป k เท่าเหมือนกันหมด ซึ่งตรงกับอาการที่เจอ

> **หมายเหตุเรื่องนิยาม:** Mini-MPL รายงาน `d = cross/(cross+co)` ไม่ใช่ δ ต้องแปลงเป็น `δ = d/(1−d)` ก่อนเทียบ ซึ่งโปรแกรมทำให้แล้ว

## 3. วิธีที่โปรแกรมใช้ตอนนี้: molecular calibration

`depol_engine.compute_depolarization`:

1. หาค่าเฉลี่ย δ\* ในช่วง **4.5–5.5 km** ซึ่งสมมติว่าเป็นอากาศบริสุทธิ์ (ไม่มีละออง)
2. สมมติว่า δ ของอากาศบริสุทธิ์คือ **δ_mol = 0.0044** (ค่า "narrowband")
3. `C = δ*_mean / δ_mol` แล้ว `δ_v = δ* / C`
4. คำนวณ C **ใหม่ทุก profile**

### ผลจากข้อมูลจริง (กลางคืน, glue แบบ robust แล้ว)

|---|---|---|---|---|
| C01 | 18:30 | 2.44 | 0.16 | 1.21 |
| C01 | 19:00 | 2.39 | 0.71 | 1.06 |
| C01 | 19:30 | 2.83 | 1.41 | 1.08 |
| C01 | 21:00 | 2.67 | 1.56 | 1.00 |
| C01 | 22:00 | **9.00** | −0.08 | 1.03 |
| C02 | 00:15 | 2.48 | 14.1 | 0.95 |
| C02 | 01:00 | 2.37 | 13.7 | 0.91 |
| C02 | 02:00 | 2.52 | 14.4 | 0.90 |
| C02 | 03:00 | 2.63 | 11.7 | 1.05 |
| C02 | 04:00 | **104.2** | 0.30 | — |
| C02 | 05:00 | 2.28 | 13.5 | 0.83 |
| C02 | 06:00 | **230.0** | −0.06 | — |

**สรุปตาราง:**
- **C จาก molecular:** ปกติได้ ~2.4–2.8 แต่บาง profile ระเบิดเป็น 9, 104, 230 ในทุกครั้งที่ SNR ช่อง ⊥ ในช่วง calibrate ใกล้ศูนย์
- **C ที่ข้อมูลบอก (เทียบ MPL):** ~0.83–1.21 ค่ามัธยฐาน C01 = 1.06 (แปรปรวน 7%) · C02 = 0.95 (ไม่นับ 04:00 และ 06:00 ที่ไม่มีข้อมูลพอ)
- สองช่องของเครื่องเรา**ไวใกล้เคียงกัน (η\* ≈ 1)** แต่ molecular ให้ ~2.5 → **δ จึงถูกหารด้วยค่าที่ใหญ่ไป ~2.5 เท่า**

การหาสาเหตุก่อนหน้านี้ยืนยันว่าไม่ใช่ปัญหาการประมวลผล: δ ที่คำนวณจาก analog ล้วน (ไม่ผ่าน glue) ก็ต่ำกว่า MPL ~2 เท่าเช่นกัน และหลังแก้ glue แล้ว δ ของโปรแกรมใกล้ δ จาก analog ล้วน (0.79–0.97 เท่า)

## 4. ทำไม molecular calibration ถึงใช้ไม่ได้กับเครื่องนี้

### สาเหตุที่ 1 · สัญญาณช่อง ⊥ ที่ 5 km อ่อนเกินไป
- δ ของอากาศบริสุทธิ์เล็กมาก (~0.004) สัญญาณ ⊥ ที่นั่นจึงเหลือแค่ ~0.4% ของช่อง ∥
- **C01 (3.75 m):** SNR ช่อง ⊥ ในช่วง calibrate มีแค่ −0.1 ถึง 1.6 **ค่า C จึงเป็น noise ส่วนใหญ่** และระเบิดเมื่อ SNR ≈ 0
- **C02 (30 m):** SNR ~12–14 ดีกว่ามาก แต่ C ก็ยังออกมา ~2.4 ไม่ใช่ ~1 แสดงว่ามีสาเหตุอื่นร่วมด้วย

### สาเหตุที่ 2 · ค่า δ_mol ขึ้นกับความกว้างของ filter
ค่า δ ของอากาศบริสุทธิ์**ไม่ใช่ค่าคงที่** ขึ้นกับว่า filter ของเครื่องกว้างแค่ไหน (แสง rotational Raman ที่ผ่าน filter มามี δ สูง):

| ความกว้าง filter | δ_mol ที่ 532 nm | C ที่เราจะได้ (δ\* ≈ 0.011) |
|---|---|---|
| แคบ (~0.2 nm) | ~0.0036 | ~3.0 |
| ค่าที่โปรแกรมใช้ (narrowband) | 0.0044 | ~2.5 |
| กว้าง (รวม rotational Raman ทั้งหมด) | 0.0144 | ~0.76 |

**ต้องรู้ spec จริงของ filter** (ความยาวคลื่นกลางและ FWHM) ถ้า filter กว้างกว่าที่สมมติ ค่า C จะสูงเกินจริงแบบที่เจอ

### สาเหตุที่ 3 · สัญญาณรบกวนเล็กๆ ในช่อง ⊥ มีผลมากที่ระยะไกล
ที่ 5 km สัญญาณ ⊥ เล็กมาก ความผิดพลาดเล็กน้อยจะทำให้ δ\* สูงเกินจริงชัดเจน:
- background ที่ลบออกไม่หมด
- afterpulse ของ PMT ช่อง ⊥ (ตอนนี้ยังไม่ได้ใส่ค่า afterpulse ของช่อง ⊥)
- แสงรั่วข้ามช่อง (cross-talk) ของ PBS

### สาเหตุเสริม · สมมติฐานว่าอากาศที่ 4.5–5.5 km บริสุทธิ์
ถ้ามีละอองหรือ cirrus บางๆ δ\* จะสูงขึ้นและ C จะใหญ่ขึ้นตาม

## 5. วิธี calibration ที่มีใช้กัน

| วิธี | หลักการ | ต้องใช้อุปกรณ์ | ข้อดี | ข้อเสีย |
|---|---|---|---|---|
| **Molecular** (ที่ใช้อยู่) | สมมติ δ ของอากาศบริสุทธิ์ | ไม่ต้อง | ทำจากข้อมูลได้เลย | ต้องมี SNR ช่อง ⊥ สูงมาก ต้องรู้ filter และต้องมีช่วงที่อากาศบริสุทธิ์จริง ใช้ไม่ได้กับเครื่องนี้ |
| **±45°** (มาตรฐาน EARLINET) | หมุนระนาบโพลาไรเซชันไป +45° และ −45° ตอนนั้นสองช่องจะได้แสงเท่ากันไม่ว่าบรรยากาศเป็นอย่างไร | อุปกรณ์หมุน (λ/2 plate หรือหมุนชุด PBS) | **ไม่ขึ้นกับบรรยากาศ**, ไม่ต้องรู้ δ_mol, ใช้สัญญาณแรงในระยะใกล้ | ต้องทดลองกับเครื่อง ต้องหมุนได้แม่นยำ |
| **Δ90** | วัดสองมุมที่ห่างกัน 90° (±45° เป็นกรณีหนึ่ง) พร้อมแก้ผลของอุปกรณ์ที่ไม่สมบูรณ์ | เหมือน ±45° | จัดการ cross-talk และ misalignment ได้ครบ | คำนวณซับซ้อนกว่า |
| **เทียบกับเครื่องอ้างอิง** | ปรับให้ δ ตรงกับอีกเครื่อง | เครื่องอ้างอิง | ง่าย | **ขึ้นกับ calibration ของเครื่องอ้างอิง** ใช้แทน calibration ไม่ได้ |

### หลักการ ±45° (Freudenthaler et al. 2009; Belegante et al. 2018)
- หมุนระนาบโพลาไรเซชันของแสงที่เข้า PBS ไป **+45°** แล้ววัด ได้ δ\*(+45°)
- หมุนไป **−45°** แล้ววัด ได้ δ\*(−45°)
- ที่ ±45° แสงถูกแบ่งเข้าสองช่องเท่ากัน อัตราส่วนสัญญาณที่วัดได้จึงเป็นความไวของสองช่องล้วนๆ

```
η* = √( δ*(+45°) · δ*(−45°) )
```

**ทำไมใช้ค่าเฉลี่ยเรขาคณิต:** ถ้ามุมหมุนคลาดไปเล็กน้อย ด้านหนึ่งจะได้ค่ามากขึ้นและอีกด้านน้อยลงพอๆ กัน การคูณแล้วถอดรากจึงหักล้างความคลาดเคลื่อนนี้ได้ ค่าที่วัดได้**ไม่ขึ้นกับบรรยากาศ**จึงใช้สัญญาณแรงที่ 0.5–2.5 km ได้ ไม่ต้องไปพึ่งช่วง 5 km ที่สัญญาณ ⊥ อ่อน

ตามรายงานของ EARLINET วิธีนี้ให้ความแม่นของ δ ที่ 532 nm ดีกว่า ±0.03

## 6. ขั้นตอนทดลอง ±45° ที่เสนอ

### 6.1 ข้อมูลที่ต้องเตรียมก่อนทดลอง

| ข้อมูล | ใช้ทำอะไร |
|---|---|
| spec ของ interference filter ทั้งสองช่อง (ความยาวคลื่นกลาง, FWHM) | เลือก δ_mol ที่ถูกต้องไว้ตรวจผล |
| ชนิดและ extinction ratio ของ PBS | ประเมินว่าต้องแก้ cross-talk ไหม |
| HV ของ PMT แต่ละช่อง ใน C01 และ C02 | η\* เปลี่ยนตาม HV ต้อง calibrate ทุกค่า HV ที่ใช้งาน |
| ตำแหน่งที่ใส่อุปกรณ์หมุนได้ | ต้องอยู่**ก่อน** PBS ในเส้นทางแสงขารับ |

### 6.2 อุปกรณ์
ทางใดทางหนึ่ง:
- **λ/2 plate** ในตัวยึดที่หมุนได้ มีสเกลองศา ใส่ก่อน PBS (หมุน plate 22.5° = หมุนระนาบโพลาไรเซชัน 45°) ถอดออกได้โดยไม่ขยับแนวแสง
- **หมุนชุด PBS + detector ทั้งชุด** รอบแกนแสง ±45° (ต้องมีตัวยึดที่หมุนได้แม่นยำ)

### 6.3 เงื่อนไขการวัด
- **กลางคืน ฟ้าใส ไม่มีเมฆต่ำ** บรรยากาศนิ่ง
- ใช้**การตั้งค่าเดียวกับตอนใช้งานจริงทุกอย่าง:** HV, discriminator, input range, bin
- ใช้การตั้งค่าที่ **photon StErr ไม่พัง** (เช่น 3.75 m ตามแบบ C01) หรือเปิด Poisson repair ไว้
- ในช่วง 0.5–2.5 km **ทั้งสองช่องควรมี SNR ≥ 20**

### 6.4 ลำดับการวัด (หนึ่งรอบ)

| ลำดับ | ตำแหน่ง | เวลา | เพื่อ |
|---|---|---|---|
| 1 | 0° (ปกติ) | 5 นาที | ค่าอ้างอิงก่อน |
| 2 | **+45°** | 10 นาที | δ\*(+45°) |
| 3 | **−45°** | 10 นาที | δ\*(−45°) |
| 4 | 0° (ปกติ) | 5 นาที | ตรวจว่าบรรยากาศไม่เปลี่ยนระหว่างวัด |

- **ทำ 2–3 รอบ** ในคืนเดียวกัน เพื่อดูว่าค่านิ่งไหม
- **จดมุมจริง, เวลาเริ่ม/จบ และชื่อไฟล์**ของแต่ละตำแหน่ง
- แยกโฟลเดอร์ไฟล์ตามตำแหน่ง (`0deg/`, `p45/`, `m45/`)

### 6.5 การประมวลผล
1. ประมวลผลไฟล์แต่ละตำแหน่งแบบปกติ (background, glue robust) **ยังไม่ต้อง calibrate**
2. คำนวณ `δ*(z) = P⊥(z) / P∥(z)` ในช่วงที่ทั้งสองช่อง SNR ≥ 20 และไม่มีเมฆ (เช่น 0.5–2.5 km)
3. ค่ามัธยฐานของ δ\* ในช่วงนั้น → `η*(+45°)` และ `η*(−45°)`
4. `η* = √(η*(+45°) · η*(−45°))`
5. ใช้ `δ_v(z) = δ*(z, 0°) / η*` กับข้อมูลทุกคืนที่ใช้การตั้งค่าเดียวกัน

### 6.6 เกณฑ์ผ่าน
- **ค่านิ่ง:** η\* ของแต่ละรอบต่างกันไม่เกิน ±5%
- **มุมถูก:** η\*(+45°) และ η\*(−45°) ควรใกล้เคียงกัน ถ้าต่างกันมาก แปลว่ามุมหมุนคลาดหรือ PBS ไม่ได้อยู่ในแนวที่คิด
- **ตรวจกับอากาศบริสุทธิ์:** หลังใช้ η\* แล้ว δ ในช่วงอากาศบริสุทธิ์ควรใกล้ δ_mol ของ filter จริง (ภายในความคลาดเคลื่อน)
- **ตรวจกับ MPL:** δ ใน BL ควรใกล้ δ ของ MPL (ใช้แค่ยืนยัน ไม่ใช่ใช้กำหนดค่า)
- **ถ้าจากข้อมูลตอนนี้ถูกต้อง** ควรได้ **η\* ≈ 1.0**

### 6.7 ต้อง calibrate ใหม่เมื่อ
- เปลี่ยน HV ของ PMT ช่องใดช่องหนึ่ง
- ถอด/ขยับ PBS, filter, PMT หรือชุดรับแสง
- เปลี่ยน discriminator หรือ input range ของ TR
- ควรตรวจซ้ำเป็นระยะ (เช่น ทุก 3–6 เดือน)

| 4 | เพิ่มโหมดประมวลผลไฟล์ ±45° (อ่านโฟลเดอร์ 0°/+45°/−45° แล้วคำนวณ η\* พร้อมเกณฑ์ผ่านในข้อ 6.6) | ลดงานมือ ลดความผิดพลาด |
| 5 | ใส่ค่า afterpulse ของช่อง ⊥ (ถ้ามีไฟล์วัด afterpulse) | ลดสาเหตุที่ 3 |

> ⚠️ **ไม่แนะนำ:** ตั้ง C = 1.0 จากการเทียบกับ MPL แล้วใช้เป็นค่าจริง เป็นการยืม calibration ของ MPL มาโดยไม่รู้ว่าถูกต้องไหม และไม่มีหลักฐานว่าค่านี้คงที่เมื่อเปลี่ยน HV

## 8. ข้อจำกัดของการวิเคราะห์นี้

- ใช้ข้อมูล**กลางคืน 2 คืน** (C01 5 profile, C02 5 profile ที่ใช้ได้)
- "C ที่ข้อมูลบอก ≈ 1.0" มาจากการ**เทียบกับ MPL** จึงถูกต้องได้ไม่เกิน calibration ของ MPL
- δ ของ MPL ใช้ได้แค่ต่ำกว่า ~2 km (สูงกว่านั้นสัญญาณ ⊥ ของ MPL จม noise)
- ยังไม่รู้ spec ของ filter และ PBS ของเครื่องเรา
